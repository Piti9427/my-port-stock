Handling Real-Time Data Gaps

Yahoo Finance can be delayed (especially for Thai stocks). The SOP says "No Buy without verified data". How should the UI handle this?

A

Hard Block (Strict SOP)

If the data is delayed or missing, the system refuses to analyze. It immediately returns a "Wait / Inconclusive Data" verdict and stops the agents.

B

Soft Warning (Provisional)

Show a yellow warning banner: "Data delayed by 15 mins". The AI still runs, but the final verdict is stamped "PROVISIONAL" until verified.

C

Manual Price Override

The system pauses. A popup asks: "We can't verify the live price. Please enter the current price from your broker app to continue."

My Recommendation: B + C

  • Show the warning (B), but give the user an input box to manually override the price (C) if they want a firm verdict.
